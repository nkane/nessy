nessy

NES emulator running in your browser via Go js/wasm + Ebiten.

gamepad: none
Keyboard (default):
  Arrows — D-pad     Z / X — A / B     Enter — Start     RShift — Select
  F1–F4 — save slot 1–4     Shift+F1–F4 — load slot 1–4

Drop a .nes file onto the screen (or "Load ROM…") to play your own game —
it stays in your browser, nothing is uploaded. Save slots persist across
reloads (IndexedDB). Gamepads use the standard mapping; "Remap keys" binds
a custom keyboard layout. Installable + works offline (PWA).
